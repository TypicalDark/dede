# Design review — SOLID / performance / correctness

dede was reviewed against SOLID/GRASP, hot-path performance, and interpreter/
timeline correctness. This records the findings, what was fixed, and what is
deliberately deferred (with the reasoning, so the deferral is a decision, not an
oversight).

## Design principles in force

- **SRP** — one subsystem per library, a strict acyclic dependency graph rooted at
  `common` (see [ARCHITECTURE.md](ARCHITECTURE.md)).
- **OCP / DIP** — adding an execution backend, disassembler, decompiler,
  introspector, or protection detector needs no edit to existing code: each is a
  factory/interface injected in (`ExecutionCore::BackendFactory`, `SessionDeps`,
  `IDetector`, …).
- **LSP** — every Strategy/Adapter honours its interface; the core asserts a
  backend's architecture matches at construction.
- **Observer / Facade / Bridge** — the core emits events without knowing its
  subscribers; the UI binds only to `IAnalysisEngine`, never to subsystem internals.
- **The GoF spine** is catalogued in [PATTERNS.md](PATTERNS.md), including the
  patterns deliberately *avoided* (Singleton, Monostate, Broker, …).

## Fixed

**Correctness (high):**
- One-operand `imul` crashed the tool (`std::out_of_range`); now handled, plus a
  dispatch-level exception net so any operand mismatch degrades to `Unsupported`
  rather than crashing on a hostile sample.
- `record()` pushed a duplicate memento on a non-retiring step, silently disabling
  fast step-back; now idempotent per tick.
- Forward `seek()` skipped macro firing and leaked queued matches; forward
  exploration now runs the full step pipeline (run points + mutating macros fire
  and get injected).

**Correctness (medium):** `shift()` undefined behaviour for over-width counts;
watchpoints now match a multi-byte access range; the State machine's
`can_mutate()` / `can_record_start()` are now enforced; `kRunForever` single-sourced
and raised.

**Performance:** snapshot reuse (no page-map copy on non-writing steps); a one-entry
read cache (sequential fetch/scan skip the map lookup — the 256-page case now
matches the 2-page case); `fetch()` fills a caller buffer instead of heap-allocating
per instruction. `dede-bench` measures it (~10 MIPS raw, ~6.8 MIPS with full
time-travel) and is guarded by a CTest.

Every fix landed with a regression test (`tests/test_regress.cpp` and friends).

## Deferred (with rationale)

- **ISP: `IAnalysisEngine` is broad.** It aggregates identity/views/control/run-
  points/macros/transparency/capture/timeline. It is intentionally the Facade's
  single public face so a UI binds to one thing; Commands and macros already depend
  only on the *narrow* `IDebugController`. If a panel-level need arises, the clean
  step is to split role interfaces (`IRegisterView`, `IExecControl`, …) that
  `IAnalysisEngine` inherits — additive, no churn. Tracked, not done.
- **Delta-encoded timeline ring.** Snapshot reuse already removed the per-step
  page-map copy; a full delta/pre-image ring (O(pages written) instead of sparse
  full anchors) is the next step for very long runs. Deferred until a workload needs
  it.
- **String-compare instruction dispatch.** `dispatch()` matches mnemonics by
  `std::string`. Readable and not yet hot enough to matter; the Flyweight decode
  cache means each address is decoded once. A perfect-hash/id switch is the drop-in
  upgrade if profiling calls for it.
- **W^X state in the Memento.** The written-page set lives in the proxy and is reset
  on restore, so a *backward* seek re-arms W^X from scratch rather than restoring the
  exact arming state. Forward replay is unaffected; noted as a minor fidelity gap.
- **Macro command-failure propagation**, **GRASP: timeline-forking rule owned by the
  Facade not the TimelineManager**, and **event construction when no run point is
  interested** — all low severity, listed for a future cleanup pass.

## Beyond the core review

The anti-analysis and effectiveness work added since the review is tracked in
[TRANSPARENCY.md](TRANSPARENCY.md) (detection coverage + roadmap) and
[EFFECTIVENESS_REPORT.md](EFFECTIVENESS_REPORT.md) (the automated 150-point score,
regenerated by `dede-eval`). The in-scope gaps that report surfaces — a decompiler
backend, a fault-delivery channel, richer capture dissection — are the honest
forward roadmap.
